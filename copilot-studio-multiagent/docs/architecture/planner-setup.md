# Microsoft Planner ボード設定

## プラン情報

| 項目 | 設定値 |
|---|---|
| プラン名 | AI-Org タスクボード |
| 紐付けTeams | AI-Org チーム |
| アクセス | CEO ＋ Power Automate サービスアカウント |

---

## バケット（カンバン列）構成

```
┌─────────────────┬──────────────────┬──────────────┬──────────┐
│ New             │ In Progress      │ Blocked      │ Done     │
│ （未アサイン）  │ （対応中）       │ （停止中）   │ （完了） │
├─────────────────┼──────────────────┼──────────────┼──────────┤
│ タスクディパッチ│ 担当エージェント │ 人間確認待ち │ 自動     │
│ が自動起票する  │ がピックアップ   │ や依存待ち   │ アーカイブ│
│ 場所            │ して移動する     │ はここ       │ される   │
└─────────────────┴──────────────────┴──────────────┴──────────┘
```

## タスクラベル（カテゴリ）定義

| ラベル名 | 色 | 用途 |
|---|---|---|
| #infra | グレー | インフラ・システムメンテナンス系タスク |
| #engineering | 青 | コード開発・技術実装タスク |
| #content | 緑 | 動画台本・コンテンツ制作タスク |
| #business | 紫 | マーケ・営業・戦略・法務タスク |
| P0 | 赤 | 最優先・CEOが今日中に判断必要 |
| P1 | オレンジ | 高優先・今週中に対応 |
| P2 | 黄色 | 通常優先・次のスプリントで対応 |

## タスクフィールド定義

各タスクには以下のフィールドを設定する：

| フィールド | 内容 | 必須 |
|---|---|---|
| タイトル | `[チーム] タスク内容の要約（50文字以内）` | ○ |
| 担当者 | 担当エージェント名 or CEOの名前 | ○ |
| 期日 | 完了目標日時 | ○ |
| ラベル | チームラベル ＋ 優先度ラベル | ○ |
| メモ | タスクの詳細・背景・完了条件 | ○ |
| チェックリスト | サブタスクの分解リスト | 任意 |

### タイトル命名規則

```
[コンテンツ] 2026-06-20 動画「AIエージェント入門」台本作成
[エンジニア] ログインページのレスポンシブ対応
[ビジネス]  〇〇社からのコラボ打診 レビュー
[インフラ]  Planner 完了済みタスク アーカイブ処理
```

## Blocked タスクの書き方ルール

Blockedバケットに移動する際は必ずメモに以下を記載する：

```
## Blocked 理由
[例: CEOのブランド方針確認が必要]

## 必要なアクション（CEOへ）
[例: Philosophy.md の「断るべき案件」セクションを更新してください]

## ブロック解除後の次ステップ
[例: 方針確認後、パートナーシップMgrが返答ドラフトを作成]

## ブロック発生日時
2026-06-16 03:00 JST
```

## Power Automate との連携

### 自動起票フロー（タスクディパッチ）

```
SharePoint /Inbox/ に新規ファイル作成を検知
  ↓
GPT-4o-mini でタスク分類・優先度判定
  ↓
Planner にタスク自動起票
  タイトル: [分類] {ファイル内容サマリー}
  バケット: New
  担当者: 分類に応じたエージェント名
  ラベル: #分類 ＋ 優先度
  メモ: 元ファイルへのSharePoint URLを含む
```

### 完了タスクの自動アーカイブフロー（ローカルサポート）

```
スケジュール: 毎週日曜 02:00 JST
  ↓
Planner の Done バケットから完了7日以上のタスクを取得
  ↓
SharePoint /Archive/YYYY-MM/ にMarkdown形式でエクスポート
  ↓
Planner からタスクを削除
```

### モーニングスタンドアップ フロー（タスクディパッチ）

```
スケジュール: 毎朝 07:00 JST
  ↓
Planner から以下を取得:
  - In Progress（対応中タスク一覧）
  - Blocked（停止中タスク一覧）
  - Done（昨日完了したタスク一覧）
  ↓
GPT-4o-mini でサマリー生成
  ↓
Teams [Morning Standup チャンネル] に投稿
  ↓
P0タスクが存在する場合 → Teams [Escalation チャンネル] にも別途通知
```
